**What do you think the CPU does?**
Executes instructions and performs calculations
The Central Processing Unit (CPU), often called the processor, resembles a part of our brain. The processor does the same thing for the computer. The processor connects to the motherboard via the processor socket.

**What role does the motherboard play in a computer?**
It connects and allows communication between all components
The motherboard resembles our skeleton and nervous system. Where it secures all the different components in place and connects them to each other. On the traditional motherboard of desktop computers, you will see various connectors that hold all your components - the CPU socket, RAM slots, expansion slots, and various ports. Each component connects thru the motherboard.

**How would you describe what RAM does?**
Stores data temporarily while the computer is running
Random Access Memory (RAM) is similar to short-term memory or working memory in our brain. Where it temporarily holds relevant information in our memory. Random Access Memory (RAM) does the same thing - it holds the data that the central processor needs to access quickly. Random Access Memory (RAM) is volatile: when the power is cut off, all contents disappear. Modern RAM modules use technologies like DDR5 or DDR6 to increase speed and performance.

**What's the main purpose of storage devices like SSDs and HDDs?**
To save data permanently even when powered off
SSD and HDD storage units are considered storage devices, comparable to our long-term memory. Data is stored long-term in storage devices. Hard disk drives (HDD) use older technology with moving parts, which limits performance. SSD drives do not have moving parts and use memory chips, allowing for much higher speeds. Hard disk drives (HDDs) are still popular due to their large capacity and low cost. Storage is connected via SATA cables or PCI Express slots.

**What does a network adapter enable a computer to do?**
Communicate with other computers and networks
The network switch allows computers to communicate with other systems. Network adapters come in both wireless and wired versions. They are often integrated into the motherboard, but can also be added as expansion cards. Network cards usually connect via PCI Express slots.

**What is the main function of the Power Supply Unit?**
To supply electrical power to all componentsTo supply electrical power to all components
The power supply is essential and requires careful consideration: if the components need more power than the power supply can provide, the system will fail. The power supply takes energy from an electrical outlet and distributes it thru several connectors, such as the main motherboard connector and Molex connectors.

**What does a graphics card primarily handle?**
Processing and outputting visual information to displays
The graphics card is comparable to the visual cortex in our brain. The graphics card receives information from the operating system and programs, then outputs the processed visual data to the screen. Graphics cards connect to PCI Express slots on the motherboard.

**What are input and output devices used for?**
To send data to and receive data from the computer
Computers have input and output devices. Input devices include keyboards, microphones, mice, and scanners. Output devices include monitors, printers, and speakers. Common connectors for these peripherals include USB, HDMI, and DisplayPort.
